Privacy policy

TSV métricas · last updated October 19, 2026

Who uses this tool

TSV métricas is a private tool used only by the creator of the YouTube channel The Slow Voyage, on the creator's own computer. It is not offered to other users.

What data it accesses

With the creator's permission, and with read-only access (youtube.readonly and yt-analytics.readonly), the tool reads data about the creator's own channel only: the list of its public videos, views, watch time, average view duration, audience retention, subscribers gained and lost, likes, comments, shares, traffic sources and thumbnail impressions. It does not read data about viewers as individuals and cannot upload, edit or delete anything on YouTube.

How the data is used

The numbers are used only to write internal reports for the creator about where viewers stop watching each episode, so the next episodes can be improved. Aggregated numbers may be read by an AI assistant that the creator runs on the same computer (Anthropic's Claude) to help write those reports.

Storage and sharing

The data and the access token are stored on the creator's computer and in the creator's private files. The data is not sold, not used for advertising and not shared with anyone else. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token on the creator's computer stops all access as well.

YouTube API Services

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy can be sent through the The Slow Voyage channel page.
